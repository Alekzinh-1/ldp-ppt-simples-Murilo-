# Desafio: Pedra, Papel e Tesoura

**Lógica de Programação**

Usando o **Git** para salvar seu projeto na nuvem, crie o jogo **Pedra, Papel e Tesoura**.

## O jogo deve ter

1. Sorteio da jogada do computador a cada rodada (pedra, papel ou tesoura).
2. Leitura da jogada do jogador (pedra, papel ou tesoura).
3. Regras: pedra vence tesoura, tesoura vence papel, papel vence pedra. Jogadas iguais resultam em empate.
4. Exibição da jogada do computador e do resultado de cada rodada (vitória, derrota ou empate).
5. Placar atualizado e exibido após cada rodada.
6. Empate não conta ponto para ninguém.
7. O torneio termina quando alguém fizer **3 vitórias**, com exibição do campeão.
8. Jogada inválida: o programa avisa e pede a jogada novamente, **sem contar como rodada**.
9. A palavra `sair` encerra o jogo a qualquer momento.
10. Ao final do torneio, exibir o total de rodadas jogadas e o total de empates.
11. Histórico das rodadas guardado em uma **lista** e exibido ao final do torneio (jogada do jogador, jogada do computador e resultado de cada rodada).
12. Ao final, perguntar se o jogador quer jogar outro torneio. Se sim, placar, contadores e histórico voltam a zero.

## Requisitos técnicos

Utilizar `while`, `if`/`elif`/`else`, `match`/`case`, `random`, lista com `append` e `for`. O código deve ser **comentado**.

## Requisitos de Git

- O projeto deve estar em um repositório no **GitHub**.
- O histórico deve ter no mínimo **3 commits**, com mensagens que descrevam o que foi feito em cada um.
- Todo o trabalho deve ser enviado ao GitHub com `git push`.

## Entrega

O **link do repositório**, com o projeto pronto e completo.
